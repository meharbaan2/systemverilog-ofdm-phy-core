## Suggested Resume Bullet

Built a fixed-point SystemVerilog OFDM PHY core with QAM mapping/demapping,
pilot insertion/extraction, cyclic prefix handling, 64-point radix-2 FFT/IFFT,
LS channel estimation, ZF/MMSE equalization via reciprocal approximation,
valid/ready stream wrappers, Python scoreboard vectors, Verilator regressions,
and iCE40 synthesis scripts.

## Honest Scope Statement

This is a synthesizable RTL prototype for the OFDM baseband datapath. It is not
a complete production modem: synchronization, coding, packet framing, timing
recovery, and exhaustive constrained-random verification are future work.
