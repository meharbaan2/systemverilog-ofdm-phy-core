# Portfolio Notes

## Suggested GitHub Description

Fixed-point SystemVerilog OFDM PHY core prototype with QAM, pilots, CP,
FFT/IFFT, LS channel estimation, equalization, and Verilator verification.

## Suggested Resume Bullet

Built a SystemVerilog OFDM PHY core prototype with fixed-point QAM
mapping/demapping, pilot insertion/extraction, cyclic prefix handling, 64-point
radix-2 FFT/IFFT, LS channel estimation, ZF/MMSE equalization, BER sanity checks,
and Verilator-based verification in Ubuntu WSL.

## Honest Scope Statement

This is a synthesizable RTL prototype for the OFDM baseband datapath. It is not
a complete production modem: synchronization, coding, packet framing, streaming
backpressure, and exhaustive constrained-random verification are future work.
